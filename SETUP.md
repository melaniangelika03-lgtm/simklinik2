# Dokumentasi Setup Proyek SIM Klinik

## 1. Persiapan
Perangkat dan aplikasi yang dibutuhkan:
- Laptop atau komputer Windows.
- Visual Studio Code.
- Laragon.
- PHP.
- MySQL.
- Browser.

## 2. Persiapan Folder
1. Siapkan folder proyek SIM Klinik.
2. Letakkan folder di dalam direktori `C:\laragon\www\`.
3. Buka folder proyek menggunakan Visual Studio Code.

## 3. Konfigurasi Database
1. Jalankan Laragon.
2. Aktifkan Apache dan MySQL.
3. Buka phpMyAdmin.
4. Buat database sesuai konfigurasi aplikasi.
5. Impor file SQL yang tersedia.
6. Sesuaikan konfigurasi koneksi database pada file aplikasi.

## 4. Menjalankan Aplikasi
1. Pastikan Apache dan MySQL aktif.
2. Buka browser.
3. Masukkan alamat `http://localhost/simklinik2/`.
4. Aplikasi SIM Klinik siap dijalankan.

## 5. Pengelolaan Proyek
Kode aplikasi disimpan di GitHub agar perubahan dan dokumentasi proyek dapat dikelola dengan lebih terstruktur.
